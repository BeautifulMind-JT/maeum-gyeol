# Blue Summer · selected visual target

User selected the first displayed mock on 2026-09-10: `selected-summer.png`. Match its cobalt surface, yellow handwritten Stay a little artwork, sunlit still-life imagery, thin Korean display type, 2-column journal and four-item navigation.

The source mock contains example records. Production starts with honest practice/writing entry points when the real journal is empty. Generic still-life backgrounds do not claim to depict a named wine bottle.

Assets: original Image Gen photography and lettering, generated from the selected mock. `summer-hero.webp` is the hero artwork with handwriting baked into the image; Korean copy and all controls remain live text. `summer-wine.webp` and `summer-still.webp` are generic illustrative cover photography.

Typography: Gowun Batang / Gowun Dodum from Google Fonts (SIL OFL), bundled locally so the design works offline. Licenses are in mobile/src. Icons: unchanged paths from official Phosphor Icons light assets (MIT), with color inherited from UI.

Sources: https://fonts.google.com/specimen/Gowun+Batang ; https://github.com/google/fonts/tree/main/ofl/gowundodum ; https://github.com/phosphor-icons/core .

The existing Capacitor runtime, local storage, Supabase authentication and RPCs remain the app foundation. No replacement prototype framework or production sample data.
