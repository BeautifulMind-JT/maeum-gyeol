# 마음결 · Mindful Moments · 0.7.0

일상의 감각에 주의를 기울이고, 알아차린 순간을 기록하며 서로의 경험을 나누는 마음챙김 앱입니다. 와인 테이스팅은 첫 연습 맥락이며 와인 없이도 사용할 수 있습니다.

## 1안: 여름의 표지

선택된 시안은 `docs/design-evidence/option1-selected.png`입니다. 코발트 홈, 노란 손글씨와 시작 버튼, 흰 바탕의 개인 서재와 기록 상세를 구현했습니다. 기록 제목은 명조, 본문은 진한 17px 글씨로 표시합니다. 오늘·발견·내 기록 세 탭을 유지합니다.

- 알아차림 → 허용하기 → 돌아오기 → 머무르기, 3분 안내와 일시정지/재개.
- 와인 이름·빈티지·상황·마음 기록·개인 돌아보기·선택 사진.
- 서재/날짜별 보기, 검색과 연습별 필터.
- 공개 피드·팔로잉·프로필·대표 기록·좋아요·댓글·소식·신고·차단.
- 백업·가져오기·수동 동기화 메뉴 제거. 이전 기기 기록이 실제로 있을 때만 일회성 이전 안내.

## 계정에 저장

`mobile/src/`는 웹과 Capacitor Android/iOS의 공통 소스입니다. Supabase Auth 이메일 OTP, PostgreSQL, 비공개 Storage를 사용합니다. 연습에는 로그인이 필요 없고, 기록 작성에는 로그인이 필요합니다.

새 기록·사진·초안은 기기 파일이나 localStorage에 쓰지 않습니다. 로그인 세션과 정적 앱 자산은 기기에 남을 수 있습니다. 입력 중인 내용과 미확인 요청은 실행 중 메모리에만 있습니다. 서버 응답을 받은 후 저장 완료를 표시하며, 전송 실패 중 화면을 닫으면 미전송 내용이 사라질 수 있음을 알립니다.

- `mg_entries`: 비공개 원본. `mg_drafts`: 계정당 하나의 비공개 초안.
- `mg_commit_draft`: 소유자/버전 검사와 요청 중복 방지.
- `mg_save_entry`: 최종 기록 저장과 해당 초안 비우기를 한 트랜잭션으로 실행.
- 저장 후 응답만 유실되면 같은 요청 ID로 결과를 확인합니다. 새 초안 생성이나 중복 기록을 만들지 않습니다.
- 다른 기기에서 변경된 내용은 덮어쓰지 않습니다. 현재 내용을 복사하거나 서버 초안을 다시 열 수 있습니다.
- 이전 계정 캐시는 같은 계정으로만 자동 이전합니다. 비로그인 캐시는 사용자가 대상 계정을 확인한 뒤 옮깁니다. 모든 서버 응답을 확인한 후 기존 캐시를 지웁니다. 실패/충돌 시 원본을 보존합니다.

`mg_public_entries`에는 의도적으로 공개한 필드만 복사하며 돌아보기 대화는 제외합니다. 공개 철회 시 공개 사본·댓글·좋아요·관련 소식을 삭제하고 사진 접근을 철회합니다. 이미 외부에 공유된 사본까지 회수하지는 않습니다.

사진은 EXIF를 제거하고 본문/썸네일 JPEG로 변환합니다. 정리 대기열의 오래된 파일은 계정 사용 중 정리하며 기록과 초안의 참조를 모두 확인합니다. 예약 정리 작업은 아직 없습니다. 계정 삭제는 Storage 사진을 지운 뒤 Auth/DB를 삭제하며 실패하면 재시도할 수 있습니다.

## 개발과 검증

Node.js 22 이상. 루트와 `mobile/`에서 각각 `npm ci`.

```sh
npm test
npm --prefix mobile test
npm run build:vercel
node scripts/check-source.mjs
npm run dev -- --host 0.0.0.0 --port 4173
```

빌드에는 `MAEUM_SUPABASE_URL`, `MAEUM_SUPABASE_PUBLISHABLE_KEY`를 제공합니다. URL과 공개용 `sb_publishable_` 키만 번들에 포함합니다. 설정 없이 빌드하면 연습만 가능하며 기기 저장 모드로 전환하지 않습니다.

개발 서버 `/preview/`는 테스트용 PostgreSQL(PGlite)과 예시 계정을 사용합니다. `/`의 화면 크기·초안 오류·응답 유실 버튼으로 재현할 수 있습니다. `tests/fixtures/`는 운영 번들에 포함되지 않습니다. 운영 연결 없이 UI와 실제 SQL 트랜잭션을 함께 검증하기 위한 환경입니다.

SQL 테스트는 소유권, 익명 접근 금지, 다른 계정/기기의 충돌, 중복 재시도, 사진 접근, 공개 철회, 계정 삭제, 기존 기록 이전을 검사합니다. 브라우저 시각 비교와 조작 결과는 `design-qa.md`에 기록합니다. 실서비스 OTP/사진 업로드, 실기기 음성/공유, iOS 컴파일과 새 APK는 이번 로컬 검증에 포함되지 않습니다.
